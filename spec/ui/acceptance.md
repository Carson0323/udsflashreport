# M6 visual acceptance / M6 视觉验收

Screenshots are structural review artifacts, not pixel-perfect golden images.
The required review sizes are 1920×1080 and 1366×768; text, state labels,
severity words, and layout must remain readable at 125% and 150% DPI.

截图是结构审查产物，不是像素级 golden image。要求检查 1920×1080 和
1366×768；在 125% 和 150% DPI 下文字、状态、严重级别文字和布局仍须可读。
