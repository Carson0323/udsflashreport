# M3 acceptance / M3 验收

## Scope / 范围

Implement the frozen UDS subset, NRC translation, 0x78 pending lifecycle, deterministic transaction matching, diagnostic-session reconstruction, and flash-session context.

实现冻结的 UDS 服务子集、NRC 翻译、0x78 Pending 生命周期、确定性 Transaction Matcher、诊断会话重建和刷写会话上下文。

## Required checks / 必需检查

```text
pytest tests/test_decoder.py tests/test_pending.py tests/test_session.py tests/test_transaction_matcher.py -q
pytest -q
python tools/oracle_diff.py --out artifacts/M3-oracle-diff.json
```

Required cases include positive/negative responses, 0x36 BSC, 0x74 max block length, 0x50 P2/P2*, pending timeout, TesterPresent auxiliary behavior, ambiguity, session switching/reset/S3 best effort, and flash sequence context.

必需覆盖正/负响应、0x36 BSC、0x74 最大块长度、0x50 P2/P2*、Pending 超时、TesterPresent auxiliary、歧义、会话切换/复位/S3 best effort，以及刷写序列上下文。

The `0x74` parser remains conservative: malformed or uncertain length fields stay visible as raw bytes and return `None`; they must not silently feed FLASH-001.

`0x74` 解析保持保守：格式错误或不确定的长度字段仍通过 raw bytes 可见并返回 `None`，不得静默进入 FLASH-001。

## Required artifacts / 必需产物

- `artifacts/M3-test-report.txt`
- `artifacts/M3-oracle-diff.json`

The oracle comparison is a decoder cross-check only. Attribution ground truth remains outside this milestone.

oracle 对拍仅用于解码交叉检查；归因 ground truth 不属于本里程碑。

## Stop condition / 停止条件

Any required automated check failing stops progression to M4.

任一必需自动化检查失败都必须停止进入 M4。
