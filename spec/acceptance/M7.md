# M7 验收说明 | M7 Acceptance

## 范围 | Scope

M7 completes the distributable Windows candidate: dependency locking, PyInstaller
onedir packaging, deployment preflight, private-corpus regression, and license
compliance review. / M7 完成可分发 Windows 候选版本：依赖锁定、PyInstaller
onedir 打包、部署预检、私有语料回归和许可证合规复核。

## Automated gate / 自动化 Gate

The following must pass before human review / 人工验收前必须全部通过：

```text
pytest -q
python tools/m7_preflight.py
python tools/build_m7.py
python tools/inject_private_corpus.py <private-input> <private-input>/UDSFlashReport_injected_cases
python tools/run_m7_private_regression.py <private-input>/UDSFlashReport_injected_cases/manifest.json <private-input>/UDSFlashReport_injected_cases/M7-private-corpus-report.json
```

Required local artifacts / 必需本地产物：

- `artifacts/M7-deploy-preflight.json`
- `artifacts/M7-build-benchmark.json`
- a PyInstaller onedir directory containing `FlashReport.exe`
- private-only injection manifest and regression report

The PyInstaller builder removes unrelated native-runtime directories from its
build search path, registers the bundled PySide6/shiboken6 directories with a
runtime hook, and requires the packaged GUI to start and exit with return code
0 under `QT_QPA_PLATFORM=offscreen` and `FLASHREPORT_SMOKE_MS`; the same smoke
also analyzes a public sample and validates the report schema. / PyInstaller
构建器会隔离无关的本机运行库搜索路径，通过运行时钩子注册随包提供的
PySide6/shiboken6 目录，并要求打包后的 GUI 在上述环境变量下完成启动、自动
退出且返回码为 0；同一自检还会分析公开样例并校验报告 schema。

BLF analysis uses `default_config()` without manual address mapping; ambiguity is
retained for the reviewer. / BLF 分析使用不含手工地址映射的 `default_config()`；
歧义保留给测试人员确认。

The GUI review surface also requires chronological frame numbering, compact CH/DLC
layout, direction/CF filters, Data-byte color blocks, evidence-row focus, light/dark
switching, and responsive rendering for large Finding results. / GUI 人工检查面还应
验证帧序号按时间递增、CH/DLC 紧凑布局、方向/CF 筛选、Data 字节色块、证据行定位、
深浅色切换，以及大规模 Finding 结果的响应式渲染。

## Human gate / 人工 Gate

Do not create a GitHub Release until the reviewer completes all items below. /
人工审核完成前不得创建 GitHub Release：

- Run the onedir package on a clean Windows 10/11 VM.
  在干净的 Windows 10/11 虚拟机运行 onedir 包。
- Verify startup, open/analyze/export, empty/error states, and no private corpus in the package.
  验证启动、打开/分析/导出、空白/错误状态，以及安装包不含私有语料。
- Review SmartScreen behavior and the final `THIRD_PARTY_NOTICES.md`.
  审核 SmartScreen 行为和最终第三方声明文件。
- Record the result in `M7-vm-verification.txt` before release.
  发布前将结果记录到 `M7-vm-verification.txt`。

## Public release boundary / 公开发布边界

The GitHub repository may receive source commits, but no GitHub Release is
authorized by this gate. / GitHub 仓库可以接收源码提交，但本 Gate 不授权创建
GitHub Release。

Before a public release, README must report real annotated-corpus metrics and
must not claim automatic responsibility attribution below the agreed threshold.
/ 公开发布前，README 必须报告真实人工标注语料指标；未达到人工约定阈值时，
不得宣称可以自动判断责任方。
