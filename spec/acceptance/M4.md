# M4 acceptance / M4 验收

## Scope / 范围

Implement the findings registry, deterministic attribution evaluators, timing
provenance, evidence contracts, first-deviation selection, and supersede
handling for the seven frozen finding IDs.

实现 findings 登记表、确定性归因 evaluator、时序来源、证据契约、首个偏差选择，以及七类冻结 finding 的 supersede 处理。

## Required checks / 必需检查

```text
pytest tests/test_attribution.py tests/test_spec_yaml.py -q
pytest -q
```

The gate covers FLASH-001 boundaries (0x401/0x402 pass, 0x403 fails as
tester/high), pending success and timeout, default versus observed-server
timing, first deviation and supersede, ISO-TP-003 evidence enrichment, and
findings.yaml/registry consistency.

门禁覆盖 FLASH-001 边界（0x401/0x402 通过、0x403 归因 tester/high）、Pending 成功与超时、default/observed-server 时序来源、first deviation 与 supersede、ISO-TP-003 证据补全，以及 findings.yaml 与代码登记一致性。

## Outputs / 产物

- `artifacts/M4-attribution-golden.json`

## Data boundary / 数据边界

Private test material outside the repository is read locally only. It is not
copied, staged, committed, or uploaded.

仓库外的私有测试资料仅在本机读取，不复制、不暂存、不提交、不上传。
