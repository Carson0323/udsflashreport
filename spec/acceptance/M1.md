# M1 acceptance / M1 验收

## Scope / 范围

Implement ASC/BLF readers, record-layer metadata passthrough, addressing, manual-pair precedence, 29-bit normal-fixed masks, 11-bit heuristic detection, and channel-isolated pair keys.

实现 ASC/BLF reader、记录层元数据透传、寻址、手工 pair 优先级、29-bit normal-fixed mask、11-bit heuristic 检测，以及按 channel 隔离的 pair key。

## Required checks / 必需检查

```text
pytest tests/test_reader.py tests/test_addressing.py -q
pytest tests/test_config_schema.py tests/test_models_instantiate.py tests/test_models_module_imports.py -q
```

Required cases include tester SA F1/E0/01, multi-channel same IDs, v0.9 mask regression, manual 11-bit pairs, functional addressing, explicit CAN FD metadata, unknown-channel accounting, and legacy `extended` rejection.

必需覆盖 tester SA F1/E0/01、多通道同 ID、v0.9 mask 回归、手工 11-bit pair、功能寻址、显式 CAN FD 元数据、未知 channel 统计和旧 `extended` 字段拒绝。

## Required artifact / 必需产物

- `artifacts/M1-blf-coverage.txt`

## Stop condition / 停止条件

Any required automated check failing stops progression to M2. A real private BLF regression remains a manual evidence requirement when such a corpus is available.

任一自动化检查失败都必须停止进入 M2；真实私有 BLF 回归在获得相应语料后补做人工证据核验。
