# M0 acceptance

## Scope

M0 establishes the repository skeleton, frozen datamodel, initial configuration schema, findings registry, sample registry, and CLI smoke-test behavior.

## Required checks

```text
pytest tests/test_config_schema.py tests/test_models_instantiate.py tests/test_models_module_imports.py -q
python tools/gen_samples.py
python -m flashreport_core.cli analyze samples/success_full_download.asc
```

## Required artifacts

- `artifacts/M0-test-report.txt`
- Five initial generated sample traces and expected JSON files.

## Stop condition

Any required check failing stops progression to M1. Frozen product, protocol, model, UI, and acceptance semantics must not be changed autonomously.
