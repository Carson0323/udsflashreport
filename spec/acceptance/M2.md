# M2 acceptance / M2 验收

## Scope / 范围

Implement ISO-TP eventization, direction-local PDU reconstruction, and the bidirectional Transport Validator for Classical CAN normal addressing.

实现 Classical CAN normal addressing 下的 ISO-TP 事件化、按方向 PDU 重建，以及消费双向 conversation 的 Transport Validator。

The reconstructor must use FF/CF only: a complete FF/CF sequence remains reconstructable when FC is absent. FC timing, BS boundaries, WAIT/OVFLW, SN, STmin, and CF timing are validator responsibilities.

重建器只依赖 FF/CF：即使缺少 FC，只要 FF/CF 完整仍必须重建成功。FC 时序、BS 块边界、WAIT/OVFLW、SN、STmin 和 CF 时序由 Validator 负责。

## Required checks / 必需检查

```text
pytest tests/test_reconstructor.py tests/test_validator.py -q
pytest -q
```

Required cases include SF, FF+CF, missing FC but reconstructable, missing CF, SN gap and wrap, timeout, WAIT, OVFLW, non-ISO-TP, CAN FD record flag, explicit addressing marker, direction isolation, BS=0, second FC after BS, PDU-end no-next-FC, CF-before-CTS, reserved STmin, and API load projection.

必需覆盖 SF、FF+CF、缺 FC 但可重建、缺 CF、SN 跳号与回绕、超时、WAIT、OVFLW、非 ISO-TP、CAN FD 记录标志、显式寻址标志、方向隔离、BS=0、BS 后第二个 FC、PDU 结束不要求下一个 FC、CF 早于 CTS、保留 STmin，以及 API load projection。

## Required artifacts / 必需产物

- `artifacts/M2-test-report.txt`
- `artifacts/M2-oracle-diff.json`

The oracle artifact records the current independent-oracle status. No external ISO-TP oracle is silently claimed where one is not available.

oracle artifact 记录当前独立 oracle 状态；没有可用的外部 ISO-TP oracle 时，不静默声称已经完成对拍。

## Stop condition / 停止条件

Any required automated check failing stops progression to M3.

任一必需自动化检查失败都必须停止进入 M3。
