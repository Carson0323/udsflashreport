# M5 acceptance / M5 验收

## Scope / 范围

Implement the public analyze API, CLI batch flow, bilingual Markdown output,
JSON output, and report-schema validation.

实现公开 analyze API、CLI 批处理流程、双语 Markdown 输出、JSON 输出和报告 Schema 校验。

## Required checks / 必需检查

```text
pytest tests/test_report.py tests/test_cli_e2e.py tests/test_api_contract.py -q
pytest -q
```

CLI exit codes are 0 for a completed analysis, 2 for unreadable/unsupported
input, 3 for invalid configuration/spec, and 4 for report validation/export
failure.

CLI 退出码约定：分析完成为 0；输入不可读或不支持为 2；配置/规格无效为 3；报告校验或输出失败为 4。

## Output contract / 输出契约

Reports contain metadata, input quality, findings ordered by deviation time,
first deviation, evidence, and a validation-safe JSON representation.

报告包含元信息、输入质量、按偏差时刻排序的 findings、first deviation、证据，以及写出前通过校验的 JSON 表示。
